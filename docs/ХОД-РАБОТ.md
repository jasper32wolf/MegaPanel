## 1. Промпт / ТЗ — что это и зачем

Файл **`Промпт для генерации проекта.md`** — полное техническое задание (версия **5.6**) на продукт:

**Мультипанель массовой генерации сайтов** = Programmatic SEO + Secure Multi-Client Lead Hub.

Ключевые идеи ТЗ:

| Тема | Суть |
|------|------|
| Архитектура | Headless-панель + **Pure SSG** (клиентские сайты = HTML/CSS/минимальный JS) |
| Site-as-Code | Манифесты сайтов в PostgreSQL JSON; полная пересборка с чистого VPS |
| Multi-tenant | Агентства / клиенты, RBAC, RLS |
| Geo + морфология | Справочник + склонения (`pymorphy3`), валидация топонимов |
| AI | Micro-infill (короткое LLM-ядро) + локальный slot-fill; дедуп SimHash/MinHash |
| Block Factory | Безопасные HTML/CSS-блоки, hash-классы, CSS-переменные |
| SEO / drip | noindex → indexed через Caddy map + worker; IndexNow; thin-content guard |
| Lead Hub | Шифрование PII, honeypot, consent, webhooks |
| Security | Argon2id+pepper, MFA TOTP, audit hash-chain, SSRF egress, DSAR |

**Как использовать промпт:**

1. Новая фича → найти раздел ТЗ (§) → реализовать → отметить в журнале (§3 / §7).  
2. Не дублировать ТЗ целиком здесь — только статус и ссылки на §ТЗ.  
3. При расхождении «сделано в README» vs «реально в коде» — править **этот файл** и код, не оставлять ложь.

Дополнительно: `Промпт.txt` (если есть в корне) — вспомогательный/черновой; **канон ТЗ = `.md` v5.6**.

## 4. Поток данных (кратко)

```text
Онбординг / seed / create_site
    → kit из block-library + theme morph (seed=site_id)
    → Site.manifest (JSONB) в Postgres
    → SiteBuilder (packages/ssg) пишет data/sites/{id}/current
    → Caddy отдаёт статику / Admin API vhost
    → Worker drip: noindex→indexed + IndexNow
    → Лиды: public POST → encrypt PII → inbox / webhook
```

## 5. Известные ограничения и предупреждения

> Перед продакшеном и перед обещанием фичи клиенту — читать этот раздел.

### 5.1. Частично / mock / stub (работает, но не «как в ТЗ на 100%»)

| Область | Факт | Риск |
|---------|------|------|
| **SERP** | `mock_serp_position` по умолчанию | Автокоррекция не по реальным выдаче |
| **FIAS/GAR** | `import_fias_stub.py` + sample CSV | Нет полного импорта справочника РФ |
| **Nominatim** | Клиент есть, pipeline не полный | Обогащение geo при validate — best-effort |
| **Wayback** | Маппинг URL, которые передали вы | Нет crawl archive.org |
| **IaC** | Terraform/Ansible placeholders | Не воспроизводимый прод «из одной кнопки» |
| **SSG compress** | В основном **gzip** | Brotli/Zstd из ТЗ не полностью |
| **Incremental SSG** | Полный rebuild страниц сайта | Не точечная инкрементальная сборка |
| **Plugins** | Точки в БД + `emit_hooks`, часто noop | Нет магазина плагинов / богатых handler'ов |
| **Custom Block Builder** | Нет визуального конструктора | Только библиотека + API create |
| **Reports** | CSV (+ JSON summary) | Не xlsx/pdf (раньше в ответах врали — убрано) |
| **Lead form action** | В блоках путь `/api/v1/leads/public` | На статическом домене нужен абсолютный URL API / proxy |
| **Calculator JS** | Inline script в HTML kit | `nh3` может вырезать script — progressive enhancement не гарантирован после sanitize |
| **Caddy Admin** | В Caddyfile `admin 0.0.0.0:2019` | На проде **нельзя** светить наружу |
| **Docker на Windows** | У пользователя мог отсутствовать Docker | Install уходит в режим «Postgres уже на :5432» или падает на migrate |
